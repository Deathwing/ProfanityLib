# ProfanityLib Data

**ProfanityLib Data** is an optional standalone dependency package for [ProfanityLib](https://www.curseforge.com/wow/addons/profanitylib).

It contains the curated wordlist used by the library's matching engine.

### What This Package Contains

* Substring terms, whole-word-only terms, and benign-word exceptions
* Every term validated against a corpus of 808,940 real character names and 17,205 guild names for zero false positives

### Who Should Install This

* Install this package together with **ProfanityLib** only when using standalone packages.
* If a dependent addon already embeds ProfanityLibData, this package is optional and does not need to be installed separately.

### What This Package Does Not Do

* No UI
* No slash commands
* No standalone player-facing functionality without ProfanityLib
